# Auto Port Allocator (Pterodactyl 2.0 Extension)

Pterodactyl 2.0 extension to automatically allocate and assign secondary ports (RCON, Query, Web/HTTP, Rust+, etc.) for game servers requiring multi-port setups (such as Rust, MTA, etc.).

## Requirements
- Pterodactyl Panel 2.0+
- PHP 8.3+
- Node.js 22+
